Lần đầu sẽ tải hình ảnh và âm thanh.

Không thể mở trò chơi

  1. Edge: mở edge://settings/system. Chrome: mở chrome://settings/system.
  2. Bật “Sử dụng tăng tốc đồ họa khi khả dụng”, sau đó khởi động lại trình duyệt.
  3. Đóng bớt tab game. Nếu vẫn lỗi, xem mục WebGL tại edge://gpu hoặc thử trình duyệt khác.

Chế độ nhẹ vẫn cần WebGL hoạt động. Không cần xóa dữ liệu trang web hay hồ sơ.
